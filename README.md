## 📌 Descripción del Repositorio

Este repositorio contiene la especificación técnica completa y el desarrollo monográfico de **El Chasis Toroidal**, una propuesta epistemológica y biofísica que desplaza el paradigma reduccionista-mecanicista de la medicina convencional hacia un modelo unificado basado en la **termodinámica de procesos irreversibles fuera del equilibrio**, la **electrodinámica cuántica tisular (QED)** y la **física de la información biológica**.

The repository contains the complete monograph and technical specification in both **Spanish** and **English**.
